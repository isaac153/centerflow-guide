# 로그인하기

## 탭에서 애플리케이션 어드민 로그인 <a href="#app-login" id="app-login"></a>

***

**상담 애플리케이션 어드민**에 로그인하는 방법은 다음과 같습니다.

### URL 접속 및 로그인하기 <a href="#url" id="url"></a>

1.  **상담 애플리케이션 어드민**의 경우 시스템 보안을 위해서 IP 또는 http 접속은 제한하고 `https://도메인` 형태로 접속합니다.

    *   상담 애플리케이션 어드민 접속 URL: [https://csappnew.centerflow.ai/admin](https://csappnew.centerflow.ai/admin)



        <figure><img src="../../../.gitbook/assets/스크린샷 2024-03-21 오후 9.27.09.png" alt=""><figcaption><p>어드민 로그인</p></figcaption></figure>


2.  아이디, 비밀번호를 이용하여 로그인 인증 절차를 수행합니다.

    <table><thead><tr><th width="106">항목</th><th>설명</th></tr></thead><tbody><tr><td>아이디</td><td>관리자 계정의 ID 입력<br> - 조건: 숫자와 영문자 조합으로만 사용 가능</td></tr><tr><td>비밀번호</td><td>부여받은 관리자 계정의 비밀번호 입력하여 로그인 후 변경 필수 <br> - 조건:<br>  1. 비밀번호는 9-16글자로 구성<br>  2. 영어 대문자가 한 글자 이상 반드시 포함 (A-Z)<br>  3. 영어 소문자가 한 글자 이상 반드시 포함 (a-z)<br>  4. 숫자가 한 글자 이상 반드시 포함 (0-9)<br>  5. 특수문자 한 글자 이상 반드시 포함( <code>!</code>, <code>@</code>, <code>#</code>, <code>$</code>, <code>%</code>, <code>^</code>, <code>&#x26;</code>, <code>.</code>, <code>*</code>, <code>(</code>, <code>)</code> )<br>  6. 연속된 문자를 3개 이상 사용할 수 없음 (abc, 123)<br>  7. 동일한 문자를 연속으로 3개 이상 사용할 수 없음 (aaa, 111)<br>  8. 비밀번호에 아이디를 포함할 수 없음</td></tr><tr><td>기억하기</td><td>로그인 화면에서 입력한 정보(아이디, 비밀번호)를 캐시에 저장했다가 다음번 로그인 시 별도 입력없이 사용할 수 있음<br>  - 웹 브라우져의 캐시를 삭제할 경우 초기화되며, 공용PC를 이용하여 상담업무를 수행할 경우 해당 설정은 반드시 비활성화한 상태로 사용해야함</td></tr></tbody></table>



    <div data-gb-custom-block data-tag="hint" data-style="info" class="hint hint-info"><p><strong>안내</strong></p><p>상담 애플리케이션 어드민 로그인 화면이 표시되지 않을 경우, 상담 애플리케이션의 방화벽 설정(접속 허용 IP)이나 PC의 hosts 설정(사내망에서는 공인 IP로 접속 불가/사내 IP로만 접속 가능)을 확인하시기 바랍니다.</p></div>

#### 로그인 실패 &#x20;

상담 애플리케이션 로그인 실패에 대한 조치 방안입니다.

#### **1) 비밀번호 오류 5회 이상인 경우 접속 제한**

상담 애플리케이션 어드민 로그인 시도 중 비밀번호를 5회 이상 실패할 경우, 접속 가능한 관리자(admin 계정 소유자)에게 계정 활성화를 요청해야 합니다.

[계정 활성화 방법](https://kakaoenterprise.gitbook.io/kicc/guide/counselling/admin/management)을 참고하여 계정을 활성화하실 수 있습니다.

<figure><img src="../../../.gitbook/assets/Group 3466053.png" alt=""><figcaption><p>상담 애플리케이션 어드민 로그인 오류</p></figcaption></figure>

#### &#x20;

#### **2) 중복 로그인에 의한 접속 제한**

상담 애플리케이션 사용 중에 비정상적으로 종료(로그아웃하지 않고 웹 브라우져 종료)한 경우 아래와 같이 중복 로그인 경고 팝업창이 발생할 수 있습니다. 해당 팝업창에서 \[확인] 버튼 선택 시 기존 접속은 강제 종료되고 마지막에 접속을 시도한 세션에 대해서만 정상적으로 사용할 수 있습니다.

## 상담 애플리케이션 어드민 메인 페이지 <a href="#admin-main" id="admin-main"></a>

**상담 애플리케이션 어드민**의 경우 시스템 관리자(MASTER 계정)와 테넌트별 관리자의 메뉴 구성과 출력되는 화면이 다르게 동작합니다. **테넌트 관리자**는 해당 테넌트에 소속된 상담사에 대해서만 모니터링 가능하고, **시스템 관리자**의 경우 전체 테넌트에 소속된 상담사에 대한 모니터링이 가능합니다.

> **테넌트별 관리자 메인 화면**

테넌트별 관리자가 상담 애플리케이션 어드민에 정상 로그인하면 아래와 같은 메인 페이지를 확인할 수 있습니다. 메인 페이지는 **통합 모니터링 현황 A** 입니다.

<figure><img src="../../../.gitbook/assets/상담 모니터링 현황 A (1).jpg" alt=""><figcaption><p>관리자 메인 화면</p></figcaption></figure>



> **상담 애플리케이션 어드민 화면**
