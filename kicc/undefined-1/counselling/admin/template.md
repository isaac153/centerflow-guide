# 템플릿 관리

## 상담 템플릿 <a href="#counselling-templlate" id="counselling-templlate"></a>

상담 템플릿 메뉴는 상담 애플리케이션이 상담 내역을 저장할 때 사용하기 위해 자동으로 문구가 추가되는 템플릿입니다. 상담 템플릿 수정은 목록의 제일 앞 **edit**을 이용합니다.

* 상담 템플릿이 적용된 상담 애플리케이션 상담결과 저장 시 템플릿 문구가 자동으로 업데이트됩니다.

## 문자 템플릿 <a href="#text-template" id="text-template"></a>

문자 템플릿 메뉴는 상담 애플리케이션에서 SMS를 발송할 때 사용하기 위해 자동으로 문구가 추가되는 템플릿입니다.

<table><thead><tr><th width="170">구분</th><th>설명</th></tr></thead><tbody><tr><td>테넌트</td><td>템플릿을 사용할 테넌트 ID</td></tr><tr><td>템플릿 종류</td><td>SMS : 90 Byte 이하로 문자 전송 시<br>LMS : 2000 Byte 이하로 문자 전송 시<br>MMS : 이미지가 포함되어 문자 전송 시</td></tr><tr><td>템플릿명</td><td>템플릿 제목</td></tr><tr><td>내용</td><td>해당 템플릿으로 추가 될 문구 내용</td></tr><tr><td>첨부파일</td><td>템플릿 종류 MMS 설정 시 이미지를 추가하여 템플릿 설정 가능</td></tr><tr><td>사용여부</td><td>사용 여부 [사용/미사용]</td></tr></tbody></table>
