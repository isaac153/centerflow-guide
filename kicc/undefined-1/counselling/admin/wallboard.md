# 윌보드



콜센터에서 사용하는 전광판 기능을 제공합니다.

### 월보드 설정 <a href="#setting" id="setting"></a>

월보드의 경우 메뉴 진입시 상담원 실적 현황은 자동으로 표시되지만 월보드에 제공할 조건(그룹, 큐, 그래프, 공지사항) 등에 대한 설정을 누락한 경우 아래의 상담사 그룹 현황과 같이 공백으로 표시될 수 있습니다. 관련 설정을 완료한 이후에 사용하시기 바랍니다.

<figure><img src="https://t1.kakaocdn.net/service_kep_docpublish/Figma/KiCC/csapp/%EC%9B%94%EB%B3%B4%EB%93%9C.png" alt=""><figcaption><p>월보드</p></figcaption></figure>

#### 화면

월보드 화면은 2022.12월 기준으로 총 8개를 제공하고 8개 모두를 선택하면 3초 간격으로 8개의 화면이 자동으로 전환됩니다.

<figure><img src="https://t1.kakaocdn.net/service_kep_docpublish/Figma/KiCC/csapp/%EC%9B%94%EB%B3%B4%EB%93%9C%20%EC%84%A4%EC%A0%95%20%ED%99%94%EB%A9%B4.png" alt=""><figcaption><p>월보드 설정 화면</p></figcaption></figure>

#### 그룹

월보드 최초 진입 시 그룹은 미설정 상태이므로 모니터링할 그룹을 반드시 선택하시기 바랍니다.

#### 그래프

월보드 최초 진입 시 아래와 같이 그래프 출력 시간이 설정되어 있습니다. 근무시간이 다를 경우 모니터링 시간대를 변경하시기 바랍니다.

### 월보드 화면 <a href="#screen" id="screen"></a>

월보드에서 제공하는 **상담사 그룹 현황, 상담사 실적 현황, 그룹 실적 현황, 큐별 콜 현황, 센터 통합 통계, 통합 모니터링 현황 A\~C** 화면으로 총 8개 화면을 제공합니다.
