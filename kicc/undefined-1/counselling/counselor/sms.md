# 알림톡/SMS 수동 발송

[카카오톡 알림톡 연동 설정](https://kakaoenterprise.gitbook.io/kicc/guide/console/kakaotalk/alim_sms)을 한 경우에 한하여, 알림톡과 SMS를 수동 발송할 수 있습니다.&#x20;



### 알림톡 수동 발송

알림톡 연동 설정을 한 경우 알림톡을 수동으로 발송할 수 있습니다.

<figure><img src="../../../.gitbook/assets/Group 3466049.png" alt=""><figcaption><p>알림톡 수동 발송</p></figcaption></figure>



상단의 알림톡 버튼을 클릭하면 알림톡 팝업이 실행됩니다.

<figure><img src="../../../.gitbook/assets/Group 3466050.png" alt=""><figcaption><p>알림톡 수동 발송 팝업</p></figcaption></figure>

알림톡을 받을 전화번호와 전달할 템플릿을 선택합니다. 탬플릿 선택 시 알림톡 내용이 확인 가능하며, 확인 후 보내기 버튼을 클릭합니다.

알림톡 템플릿은 비즈메시지 어드민에서 등록 후 검수/승인의 과정을 거칩니다.&#x20;

{% hint style="info" %}
[**비즈메시지 어드민 바로가기 ↗️**](https://bizmsg-web.kakaoenterprise.com/user/login)

* 비즈메시지 어드민에서 발송하고자 하는 우리 회사만의 알림톡 템플릿을 등록 후, 검수/승인의 과정을 거칩니다 (1\~2 영업일 소요)
* 비즈메시지 어드민의 ID/PW와 가이드는 센터플로우 콘솔에서 [카카오톡 알림톡 연동 설정](https://kakaoenterprise.gitbook.io/kicc/guide/console/kakaotalk/alim_sms)을 한 고객사에 한하여, 서비스 개통일 이전에 별도 이메일로 안내됩니다.&#x20;
{% endhint %}



### SMS/LMS/MMS 수동발송

SMS 수동 발송 기능은 단독으로는 사용이 불가하며, 알림톡 연동 설정을 한 경우 알림톡을 수동으로 발송할 수 있습니다.

<figure><img src="../../../.gitbook/assets/Group 3466051.png" alt=""><figcaption><p>SMS 수동 발송</p></figcaption></figure>

상단의 SMS 버튼을 클릭하면 SMS 발송 팝업이 실행됩니다.

<figure><img src="../../../.gitbook/assets/Group 3466052.png" alt=""><figcaption><p>SMS 수동 발송 팝업</p></figcaption></figure>

SMS를 받을 휴대폰번호와 발신번호를 선택한 후, 전달할 메시지를 입력하거나 템플릿을 선택하여 보내기 버튼을 클릭하여 발송합니다.&#x20;

이미지 업로드 버튼을 클릭해 JPG 형식의 이미지를 첨부할 수 있습니다.

{% hint style="info" %}
[문자 템플릿 등록 안내 ↗️](https://kakaoenterprise.gitbook.io/kicc/guide/counselling/admin/template#text-template)
{% endhint %}
