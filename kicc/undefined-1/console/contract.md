# 계약 관리

**계약 관리** 메뉴에서는 상세 서비스 신청 내역을 확인하고 서비스를 해지할 수 있습니다.

{% hint style="info" %}
**안내**

* 플랜 변경, 라이센스 수량 변경, 서비스 일시 정지 등 계약 변경 관련 요청은 [서비스 지원 문의](https://centerflow.kakaocloud.com/support)를 남겨주시면 담당자가 2-3영업일 내로 연락드립니다.&#x20;
{% endhint %}

### 서비스 해지 <a href="#unsubscribe" id="unsubscribe"></a>

\[신청 취소] 또는 \[서비스 해지(요청)] 버튼을 클릭하여, 서비스 이용 계약을 해지할 수 있습니다. \
단, 회원 상태에 따라 즉시 해지 가능 여부 및 재신청 가능 여부가 달라집니다.

* **시작 요청 전**: \[신청 취소] 버튼 클릭 시, 구독 신청 정보가 즉시 삭제됩니다.
  * 단, 기존 신청 정보는 다시 확인할 수 없으며 홈페이지에서 새롭게 구독 신청 가능합니다.
* 시**작 요청 완료, 테스트 가능**: \[서비스 해지] 버튼 클릭 시, 최초 결제 금액이 전액 환불되며 즉시 ‘미사용’ 상태로 전환됩니다.
  * 관계 법령에 따라 ‘미사용’ 전환 후 5일 뒤 계정 및 서비스 데이터가 자동 삭제되어 재로그인 불가합니다.
* **이용 중**: \[서비스 해지 요청] 버튼 클릭 시, 서비스 담당자에게 해지 요청이 즉시 접수됩니다.
  * 서비스 담당자가 별도로 연락을 드려 서비스 이용 금액을 최종 정산합니다.
  * 정산이 정상 완료되면, 서비스가 정상 해지됩니다.
  * 관계 법령에 따라 ‘미사용’ 전환 후 5일 뒤 계정 및 서비스 데이터가 자동 삭제되어 재로그인 불가합니다.

{% hint style="warning" %}
**주의** \
일시 정지 상태에서는 콘솔에서 서비스를 해지할 수 없습니다. 서비스 즉시 해지 희망 시, [서비스 지원 문의](https://centerflow.kakaocloud.com/support)를 남겨주시면 담당자가 2-3영업일 내로 연락드립니다.
{% endhint %}
