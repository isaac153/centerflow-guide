# 키워드별 답변 설정 (AI 답변 추천)

**서비스 관리 > AI 전화 음성봇 > AI 봇 답변 설정 > 키워드별 답변 설정** 메뉴에서는 '문의 답변 설정' 메뉴의 기본 문의 유형에 없는 문의 사항에 대해, 문의 내용의 주요 키워드와 답변 세트를 입력할 수 있습니다.&#x20;

봇과 대화 시, 먼저 '문의별 답변 설정'에 입력한 문의 중에서 우선적으로 검색하여 답변하며, 여기에 없는 문의 항목에 대해서만 '키워드별 답변 설정'에 등록된 키워드/예시질문/답변으로 검색하여 답변합니다.&#x20;

<figure><img src="../../../.gitbook/assets/image (184).png" alt=""><figcaption><p>키워드별 답변 설정 동작 방식</p></figcaption></figure>

{% hint style="info" %}
**안내**

* '문의별 답변 설정'에 입력한 문의가 '키워드별 답변 설정'에 등록한 문의보다 우선적으로 답변되기 때문에, '문의별 답변 설정'에 이미 있는 세부 문의라면 해당 메뉴에서 추가해주시고, '키워드별 답변 설정'에는 '문의별 답변 설정'에 없는 문의에 대해서만 입력합니다.&#x20;
{% endhint %}

## **데이터 입력** <a href="#enter-data" id="enter-data"></a>

1.  <mark style="background-color:yellow;">**\[데이터 추가]를 클릭합니다.**</mark>\
    회원 상태가 '테스트 가능', '이용 중' 단계일 경우, \[정보 수정] 버튼을 먼저 클릭 후, \[데이터 추가]를 클릭합니다.

    <figure><img src="../../../.gitbook/assets/image (140).png" alt=""><figcaption><p>데이터 추가<br></p></figcaption></figure>
2.  <mark style="background-color:yellow;">**추가할 AI 상담사의 답변 데이터에 알맞은 키워드를 입력하고 \[추가] 버튼 또는 \[Enter] 키를 클릭합니다.**</mark>

    * 추가한 키워드 중, 전체를 대표하는 키워드의 체크박스를 클릭해 대표 키워드를 설정합니다. <br>

    <figure><img src="../../../.gitbook/assets/스크린샷 2024-11-25 오후 5.46.13.png" alt=""><figcaption></figcaption></figure>


3. <mark style="background-color:yellow;">**고객이 직접 질문에 사용할 만한 문장을 예시 질문 발화로 입력합니다.**</mark>
   * **예시 질문 발화와 고객의 실제 질문을 비교해 더 정확한 답변을 제공합니다.**
     * 최소 2개에서 최대 5개까지 예시 질문 발화를 입력해주세요.
     * 물음표(?)와 느낌표(!) 등의 문장부호 없이, 띄어쓰기만 적용된 문장으로 입력해주세요
4. <mark style="background-color:yellow;">**키워드와 관련된 AI 상담사의 답변을 입력합니다.**</mark>
   * **답변의 내용도 검색의 대상에 포함됩니다.**&#x20;
   * **답변은 입력한 값을 음성 합성하여 출력됩니다. 아래의 내용을 참고하여 알맞게 데이터를 입력해 주세요.**
     * 맞춤법과 띄어쓰기를 바르게 적용해 주세요.
     * 쉼표(,)와 마침표(.) 등의 문장부호를 적절히 사용해야 자연스러운 끊어 읽기가 가능합니다. 올바른 처리를 위해서는 쉼표 사용 후 한 칸 띄어 써주세요.
     * 전화번호, 이메일, URL, 날짜, 시간이나 영문 알파벳과 같은 기본적인 문자열은 자동 처리하여 읽어줍니다. (참고 가이드 -[ 지원하는 문자 코드](https://guide.centerflow.kakaocloud.com/undefined-1/console/ai_config/response#tts))
     * 의도대로 합성되지 않는 텍스트는 'SSML 태그'를 사용하여 입력합니다. (참고 가이드 -[ SSML 태그](https://guide.centerflow.kakaocloud.com/undefined-1/console/ai_config/response#ssml))&#x20;
5. <mark style="background-color:yellow;">**\[확인] 버튼을 클릭하여 입력한 데이터 세트들을 저장합니다.**</mark>
   * \[데이터 추가] 또는 \[삭제] 버튼을 클릭하여 입력 전/후의 데이터 세트를 추가/삭제할 수 있습니다.<br>
6. <mark style="background-color:yellow;">**팝업에서 입력된 데이터는 ‘등록 전’ 상태로 화면에 노출되고, 회원 상태에 따라 \[저장] 또는 \[배포] 버튼을 클릭하여 최종 저장합니다.**</mark>
   * 수정/삭제가 필요한 데이터의 경우 마우스 오버 시 노출되는 버튼을 클릭하여 수정/삭제가 가능합니다.
   * 여러 데이터를 한 번에 삭제하고자 할 때는 좌측 체크박스를 클릭하고 우상단의 \[삭제] 버튼을 클릭합니다.

<figure><img src="../../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>

### 💡 **키워드 입력시 주의사항**

* **키워드는 최소 2개, 최대 20개까지 입력 가능합니다.**
  * '대표 키워드'도 일반 키워드와 동일한 가중치로 검색 시 적용되며, 리스트/통계 상에서의 구분자로만 사용되는 용도입니다. <br>
* **키워드는 고객 발화와 '완전 일치' 시에만 매칭되어 답변이 출력됩니다.**&#x20;
  * 고객이 실제로 발화하는 패턴에서 자주 등장하는 단어를 입력합니다.&#x20;
  * 동의어도 함께 입력합니다.&#x20;
  * 형태소 분절시 최소 단위를 키워드로 입력하는 것이 좋습니다
  * 입력 예시)
    * 고객의 발화: "체험 상품 반품 어떻게 해?", "무료 이벤트 상품 반품 비용 있어?"&#x20;
    * 입력 키워드: **'체험', '무료', '이벤트'**
