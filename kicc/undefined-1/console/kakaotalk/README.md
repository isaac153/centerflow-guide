# 카카오톡 연동 서비스 설정

**서비스 관리 > 카카오톡 연동 서비스** 메뉴에서는 카카오 알림톡/SMS를 연동할 수 있습니다. 카카오톡 연동 서비스 메뉴는 구독 신청 시 선택 옵션을 추가하지 않았더라도 누구나 접근하여 추가 설정할 수 있습니다.&#x20;

### 카카오톡 연동 서비스 맞춤 설정

카카오톡 연동 서비스를 맞춤 설정하면, 전화음성봇의 알림톡 자동 발송 기능을 사용할 수 있습니다. 맞춤 설정은 알림톡/SMS 연동 설정으로 구성됩니다.

{% hint style="success" %}
센터플로우에서는 카카오톡 서비스와의 연동을 통해 보다 효과적인 상담을 지원합니다.  \
