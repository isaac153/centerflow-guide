# 콘솔 가이드

## 센터플로우 콘솔

센터플로우 콘솔은 고객센터 업무 환경에 맞게 AI컨택센터 서비스를 사용할 수 있도록 서비스 맞춤 설정 및 관리 기능을 제공합니다. 콘솔은 센터플로우 서비스에 회원 가입을 완료한 회원만 이용할 수 있습니다.

홈페이지에서 회원 가입 후 구독 신청을 완료하면, 콘솔에서 신청한 서비스를 조회하고 서비스를 맞춤 설정할 수 있습니다.

{% hint style="info" %}
**안내**

* 콘솔은 회사/단체 당 1개의 계정으로 접속 가능합니다.
* 라이센스 신청 후 발급된 상담사 및 관리자 계정은 상담앱 전용 계정이므로, 콘솔에서 이용 불가능합니다.&#x20;
{% endhint %}

### **회원 상태별 접근 가능한 콘솔 메뉴**

센터플로우 회원은 총 6가지 회원 상태 중 한 가지 상태를 갖습니다. 회원 상태는 콘솔 화면의 좌측 상단에서 확인할 수 있습니다. 회원 상태별 접근 가능한 콘솔 메뉴는 다음과 같습니다.

<table><thead><tr><th width="143.33333333333331">회원 상태</th><th width="410">설명</th><th>접근 가능한 콘솔 메뉴</th></tr></thead><tbody><tr><td>미사용</td><td>회원 가입은 완료했으나, 홈페이지에서 서비스 구독을 신청하지 않은 상태 (신규 회원 또는 구독 취소 회원)</td><td>계정 관리만 접근 가능</td></tr><tr><td>시작 요청 전</td><td>구독 신청을 완료했으나, 콘솔에서 서비스 시작 요청을 하지 않은 상태</td><td>모든 메뉴 접근 가능</td></tr><tr><td>시작 요청 완료</td><td>콘솔에서 서비스 시작 요청 및 최초 결제를 완료했으나, 서비스 테스트일 및 서비스 개시일이 도래하지 않은 상태</td><td>모든 메뉴 접근 가능</td></tr><tr><td>테스트 가능</td><td>서비스 개시일 전, 테스트용 전화 번호가 발급되어 서비스 테스가 가능한 상태</td><td>모든 메뉴 접근 가능</td></tr><tr><td>이용 중</td><td>서비스 개시일을 기점으로 서비스가 정상 제공 중인 상태</td><td>모든 메뉴 접근 가능</td></tr><tr><td>일시정지</td><td>서비스를 이용 중이었으나, 결제 오류, 사용자 요청 등으로 서비스 사용을 일시적으로 중단한 상태</td><td>서비스 관리 메뉴 제외한 모든 메뉴 접근 가능</td></tr></tbody></table>
