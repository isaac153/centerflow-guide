# 상담앱 맞춤 설정

## 상담 애플리케이션

**서비스 관리 > 상담 애플리케이션** 메뉴에서는 상담 애플리케이션 서비스를 맞춤 설정하고 설정 정보를 조회할 수 있습니다.

### **상담 애플리케이션 접속 방법 및 권한**

구독 신청 시 입력한 라이센스 수량만큼 상담 애플리케이션 접속 계정이 발급됩니다. 권한 별 계정 정보는 테스트 가능 시점에 담당자 이메일을 통해 별도 안내됩니다.

### 상담앱 맞춤 설정

상담 애플리케이션 메뉴에서 맞춤 설정한 내용을 바탕으로, 우리 회사만의 상담 애플리케이션 테넌트가 생성됩니다. 맞춤 설정은 상담 환경 설정, IVR 스크립트 설정, 지식 검색 설정(상담앱 프리미엄 이용 회원) 순으로 진행합니다. \
각 메뉴에 대한 설정은 해당 탭에서 진행합니다.

{% hint style="info" %}
**안내**

서비스를 시작 요청하려면, 모든 메뉴를 필수적으로 설정 완료해야 합니다
{% endhint %}

### 상담앱 테스트

맞춤 설정한 내용을 토대로 상담 애플리케이션이 정상 동작하는지 테스트할 수 있습니다. 시작 요청을 완료한 후, 테스트 가능 시점에 담당자 이메일을 통해 상담앱 접속 계정 및 테스트 전화 번호가 별도 안내됩니다.&#x20;

테스트 기간 동안 테스트 전화 번호에 전화를 걸고 상담앱에서 전화를 받아, 실제 상담사의 상담 환경을 검수할 수 있습니다.\
