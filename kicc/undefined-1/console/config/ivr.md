# IVR 스크립트 설정

**서비스 관리 > 상담 애플리케이션 > IVR 스크립트 설정**에서는 고객이 고객센터로 전화하여 상담사나 봇으로 연결되기 전의 인사말이나 상담 유형에 따른 서비스 안내 멘트를 설정할 수 있습니다.

<figure><img src="https://t1.kakaocdn.net/service_kep_docpublish/Figma/KiCC/IVR%20%EC%8A%A4%ED%81%AC%EB%A6%BD%ED%8A%B8%EC%84%A4%EC%A0%95.png" alt=""><figcaption><p>IVR 스크립트 설정</p></figcaption></figure>

{% hint style="info" %}
&#x20;**안내**

* 해당 페이지는 ‘상담 환경 설정’ 탭을 완료한 후에 진입이 가능합니다. (상담 환경 설정 미 작성시 알림창이 노출되며 진입 불가)
* 고객 응대 근로자 보호 안내 멘트 및 비운영 시간 멘트는 고정되어 수정이 불가합니다.
* 비운영 시간 멘트는 설정한 운영 시간 정보에 맞추어 답변이 셋팅됩니다. (단, 상담 환경 설정에서 휴일, 업무 종료 시간, 휴게 시간을 미설정 시 멘트 미출력)
* 고객 센터가 연중 무휴 또는 24시간으로 운영되거나 휴게 시간이 없을 경우 안내 멘트가 출력되지 않습니다.
* 서비스 안내 멘트는 ‘상담 환경 설정’ 탭의 ‘상담 업무 배정’에서 담당 상담 업무 유형이 2개 이상일 경우 필수로 입력해야합니다. (단, 1개일 경우 입력 불가)
* 홈페이지에서 제공되는 스크립트 외 개인화된 IVR 스크립트 설정이 필요하다면, [서비스 담당자에게 문의](https://centerflow.kakaocloud.com/support)해 주세요.&#x20;
{% endhint %}

## &#x20;IVR 스크립트 수정 <a href="#modify" id="modify"></a>

{% hint style="info" %}
**안내**

* IVR 스크립트 수정은 테스트 가능 단계에서부터 수정하실 수 있으며, 스크립트 오른쪽 상단의 하늘색 ‘수정’ 버튼을 눌러 수정할 수 있습니다.
* 내용을 수정한 뒤, 임시 저장 버튼을 누르면 수정하신 내용이 임시 저장됩니다.
* 내용 수정을 완료한 뒤, 왼쪽 아래의 파란색 ‘수정 완료’ 버튼을 누르면 수정이 요청되며, 반영까지는 최대 2-3영업일 소요됩니다.
{% endhint %}
