# 지식 검색 설정

**서비스 관리 > 상담 애플리케이션 > 지식 검색 설정** 메뉴에서는 상담 애플리케이션에서 사용할 상담 지식 데이터를 업로드할 수 있습니다. **지식 검색 설정** 메뉴에서 설정한 내용은 실제 상담 애플리케이션 상담 지식 검색 서비스에 연동됩니다.

{% hint style="info" %}
**안내**

**상담앱 프리미엄 플랜** 이용 회원 대상으로 제공하는 기능입니다.
{% endhint %}

## **데이터 입력**

1.  **\[데이터 추가]**&#xB97C; 클릭하여 새로운 데이터를 입력합니다. <br>

    <figure><img src="../../../.gitbook/assets/image (133).png" alt=""><figcaption><p>지식 검색 설정_최초 진입</p></figcaption></figure>
2. 추가할 데이터에 알맞은 키워드를 입력하고 \[추가] 버튼을 클릭합니다.
3. 카테고리, 키워드가 설명하고자 하는 관련 상담 지식을 입력합니다.
4.  \[저장] 버튼을 클릭하여 입력한 데이터 세트들을 저장합니다.<br>

    <figure><img src="../../../.gitbook/assets/image (134).png" alt=""><figcaption><p>데이터 추가<br></p></figcaption></figure>
5. 입력된 데이터는 ‘등록전’ 상태로 화면에 노출되고, \[저장] 버튼을 클릭하여 최종 저장합니다.
   * 수정/삭제가 필요한 데이터의 경우 마우스 오버 시 노출되는 버튼을 클릭하여 수정/삭제가 가능합니다.
   * 여러 데이터를 한 번에 삭제하고자 할 때는 좌측 체크박스를 클릭하고 우상단의 \[삭제] 버튼을 클릭합니다.<br>
